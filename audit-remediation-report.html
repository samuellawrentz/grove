Decisions & open notes

panic = "unwind" — locked. Restores the StepJournal rollback + TerminalGuard Drop that init/add/register rely on; release binary now matches dev behavior.
Resolver precedence — reconciled in favor of the DB-recorded kind (grove pins identity at launch; the state file owns liveness, not identity). Previously the resolver and the app-side merge contradicted each other.
Sync diverged default branch — current update_default_branch is an unconditional update-ref and will discard local-only commits if the local default diverges. Behavior is now pinned by test and carries a WARNING/TODO to make it ff-only if any caller ever commits to the local default.
